# Ray Tracer V2

Ray Tracer V2

An updated and improved remake of my original C++ ray tracer, developed as part of a university 3D programming assignment in 2019.

This version builds upon the original implementation with bug fixes, performance improvements, and PNG image output using stb_image/stb_image_write instead of the original PPM format.

The project explores the fundamentals of ray tracing and 3D computer graphics, including custom 3D vector mathematics, ray-object intersection tests, and pixel-by-pixel image rendering using orthographic projection.
Features

    Custom implementation of 3D vectors, points, and mathematical operations.
    Ray-object intersection tests for spheres, planes, oriented bounding boxes (OBBs), and triangles.
    Closest-intersection detection for overlapping objects.
    Orthographic ray casting and pixel-by-pixel rendering.
    Distinct colours for each geometric primitive.
    PNG image output using the stb image library.
    Bug fixes and improved rendering performance compared to the original implementation.

Technologies

    C++
    C++11 / C++14 / C++17
    Custom ray tracing and vector mathematics
    stb_image_write for PNG image generation

About

This project revisits my original 2019 university assignment, with a focus on improving the implementation while preserving its core functionality and educational purpose.

ChatGPT and Google Gemini were used as supplementary tools for debugging assistance, identifying potential issues, and exploring possible improvements. The project remains a hands-on exploration of ray tracing and the fundamentals of 3D computer graphics.
